Nullclaw 爱快插件安装说明

一、安装后先在应用配置中填写以下项目：
- 模型提供商
- 默认模型
- 模型接口 Base URL
- 模型接口 API Key
- 模型接口模式
- 网关需要配对
- 网关访问令牌

二、局域网聊天建议配置：
- 网关需要配对：`false`
- 网关访问令牌：自定义一串 16 位以上、无空格的令牌
- `/chat` 页面里的访问令牌必须与页面配置中的网关访问令牌完全一致

三、模型接口说明：
- `Base URL` 请填写你自己的模型网关地址
- `API Key` 请填写你自己的密钥
- `接口模式` 请按你实际模型网关支持的协议选择，例如 `responses` 或 `chat_completions`

四、安装完成后建议验证：
- 根页面：`http://设备地址:端口/`
- 健康检查：`http://设备地址:端口/health`
- 聊天页面：`http://设备地址:端口/chat`

五、聊天页面说明：
- `检查` 只验证当前服务是否可达
- 输入消息后会通过本地同步桥转到 Nullclaw 处理
- 成功时页面只显示模型返回的正文内容

六、第三方接入路径：
- 飞书：`/lark`
- Telegram：`/telegram`
- Slack：`/slack/events`
- 通用 Webhook：`/webhook`
